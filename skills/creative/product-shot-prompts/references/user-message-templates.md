# User Message Templates

## Bootstrap Message (one-time, with all reference images)

```
MODE: BOOTSTRAP

اینا کل کتابخونه مرجع منن. استایل مشترکشون رو استخراج کن،
Section A رو کامل پر کن، و فایل کامل .md رو بهم بده که ذخیره کنم.

brand_id: <brand name>

خروجی رو جایگزین فایل قبلی کن. از این به بعد حافظه‌ات همینه.
```

## Daily Use Message (every time)

```
عکس محصول جدید. طبق حافظه قفل‌شده پرامپت بساز.
variants: 3
```

Just send this + product image + the .md file. No extra explanation needed — everything is inside the file.
